# Contributing

Keep changes safe, local, and reproducible. For a new scenario, add a typed simulated event, ATT&CK mapping, Sigma intent, detection rule, validation expectation, incident runbook, and tests. Run `pytest`, `ruff check .`, and `python -m soc_lab validate` before proposing a change.

Never add active offensive behavior, external targets, secrets, personal data, or unreviewed telemetry samples.
