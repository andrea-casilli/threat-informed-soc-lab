# T1059.004 — Unix Shell

1. **Detection:** `UNIX-SHELL-EXECUTION-001` matches normalized `sh`, `bash`, or `zsh` process metadata.
2. **Validation:** The simulation emits a record only; it never executes its command string.
3. **Triage:** Check command metadata, parent process, user context, and the simulation marker.
4. **Containment:** Preserve logs and isolate a lab VM only under explicit authorization.
5. **Eradication:** Remove unauthorized lab scripts; this project does not deploy persistence.
6. **Recovery:** Return the lab to baseline and confirm process telemetry.
7. **Lessons Learned:** Improve parent/child process context and test the adjusted rule.
