# Methodology

1. Define a safe scenario and expected telemetry.
2. Map it to an authoritative ATT&CK technique.
3. Implement a testable detection hypothesis.
4. Simulate only local events and validate the expected rule.
5. Record coverage from observed validation results.
6. For failures, retain the gap, improve the telemetry/rule, and retest.

This is threat-informed defense: behavior, evidence, detection, and validation are connected rather than maintained as separate artifacts.
